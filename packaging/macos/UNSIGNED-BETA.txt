TitanSkies unsigned Apple Silicon beta
=====================================

This DMG is an unsigned (ad-hoc signed) beta. It is not Developer ID signed
or notarized. macOS Gatekeeper will warn that the app is from an unidentified
developer. That warning is expected. Do not treat this channel as a
production security boundary.

Install for this user only:

1. Open TitanSkies.app from this disk image.
2. Choose Install for Me. The app copies itself to ~/Applications/TitanSkies.app
   and relaunches from that location. Background services are never registered
   from a DMG or translocated path.
3. If macOS blocks the first open, use System Settings → Privacy & Security
   to allow TitanSkies, or right-click Open, after you have verified the published
   SHA-256 of this DMG.

Closing the window leaves the local web service (127.0.0.1:8080) and the
15-minute ingest job running. Use Settings to stop, restart, repair, update,
or uninstall.

Do not copy Node, Python, or other runtimes out of the app. Do not execute the
rollback copy stored under Application Support; the in-app updater restores it
to ~/Applications first.
