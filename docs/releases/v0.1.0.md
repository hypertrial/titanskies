# TitanSkies 0.1.0

TitanSkies 0.1.0 is the first production macOS release for Apple Silicon Macs running macOS 13 or later.

## Highlights

- A self-contained native app with bundled Node.js and Python runtimes.
- Per-user installation and background services without administrator access.
- Developer ID signing, Hardened Runtime, notarization, and stapling.
- User-initiated updates authenticated by a signed Ed25519 manifest and SHA-256 artifact digest.
- Transactional application replacement with service health validation and automatic rollback.

## Installation

Download `TitanSkies-0.1.0-macos-arm64.dmg`, open it, and choose **Install for Me**. TitanSkies installs to `~/Applications/TitanSkies.app` and keeps its data in the user Library folders documented in [the macOS guide](../MACOS.md).

This release supports Apple Silicon only. It does not support Intel Macs or the Mac App Store.
