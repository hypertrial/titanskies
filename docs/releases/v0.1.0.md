# TitanSkies 0.1.0

TitanSkies 0.1.0 is the first production release of the canonical v8 application across Docker, native Omarchy/systemd Linux, and the public Vercel site.

## Highlights

- One multi-architecture `linux/amd64` and `linux/arm64` GHCR image for Docker Compose on supported macOS, Windows, and Linux hosts.
- A no-sudo Omarchy installer with systemd user services, persistent 15-minute ingest, desktop entry, health-checked activation, rollback, and data-preserving uninstall.
- Offline-key Cosign verification for release checksums and the immutable container digest.
- Vercel Pro deployment with authenticated 15-minute ingestion and transactional Vercel Blob publications.
- The v8 37-hour FireWork/HRRR smoke forecast, observations, incidents, source status, and deterministic demo mode.

There is no native macOS application. Use Docker Desktop on macOS or the hosted site.
