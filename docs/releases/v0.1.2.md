# TitanSkies 0.1.2

TitanSkies 0.1.2 is the first public production release of the canonical v8 application for Docker hosts and the public Vercel site. The unpublished `v0.1.0` and `v0.1.1` tags remain unchanged as release-validation audit records.

## Highlights

- One public GHCR image with `linux/amd64` and `linux/arm64` variants for supported Docker hosts on Linux, macOS, and Windows.
- Separate Compose web and ingest services, persistent publication/cache volumes, loopback binding by default, and immediate plus 15-minute ingest.
- Keyless GitHub OIDC signing of the immutable image digest with BuildKit SBOM and SLSA provenance attestations.
- Release validation supports current BuildKit provenance while requiring the exact clean source revision and repository.
- Vercel Pro deployment with authenticated 15-minute ingestion and transactional Vercel Blob publications.
- The v8 37-hour FireWork/HRRR smoke forecast, observations, incidents, source status, and deterministic demo mode.

macOS and Windows users run TitanSkies with Docker Desktop or use the hosted site.
